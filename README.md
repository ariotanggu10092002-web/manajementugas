# UAS Pemrograman Komputer - Sistem Manajemen Tugas

Proyek ini dibuat untuk memenuhi tugas akhir (UAS) mata kuliah Pemrograman Komputer. Aplikasi ini dirancang untuk membantu pengguna dalam mengelola, mencatat, dan memantau tugas secara efektif.

## Fitur Aplikasi
* **Manajemen Tugas:** Menambah, mengedit, dan menghapus daftar tugas (CRUD).
* **Status Progres:** Memantau tugas yang belum selesai, sedang dikerjakan, dan selesai.

## Teknologi yang Digunakan
* **Bahasa Pemrograman:** Java
* **Build Tool:** Maven

## Cara Menjalankan Aplikasi
1. Buka proyek menggunakan IDE (seperti NetBeans atau IntelliJ IDEA).
2. Pastikan dependensi Maven terunduh lengkap via `pom.xml`.
3. Jalankan file utama (*Main class*) proyek ini.
